Where the control files live and how this add-on writes to them.

GitHub token

Needed only to save. A fine-grained personal access token for with Contents: Read and write, stored privately in this add-on (not in any web page). Create one on GitHub.

How to create the token (fine-grained)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick LTL_Viewer. Do not use "Public repositories (read-only)" — that option can never write.
  3. Repository permissions → Contents → Read and write. Nothing else is needed.
  4. Generate, paste it above, Save token. The pill in the sidebar should say "can write".

Editing an existing token's access or permissions keeps its value — after changing it on GitHub just click Re-check token here.

How it works

Each card edits on the branch through the GitHub contents API. Installs re-read that file every 15 minutes and before each run, so a saved change reaches everyone within a quarter of an hour. The older GitHub Pages admin page and .github/scripts/control.ps1 edit the same files and keep working.

Site access: Firefox grants an installed add-on access to SharePoint and GitHub only when asked. If the roster or a save fails with a permission error, use Grant site access in the sidebar.
